# А.Профи — оболочка дашборда

Статическая страница для открытия существующего приложения Google Apps Script внутри iframe.

Проверка 24.10.2026: страница опубликована, Apps Script обновлён до версии 4 с ALLOWALL с согласия владельца. Прямое приложение загружает актуальные данные. Внутри оболочки в проверенном Chrome окно остаётся пустым; причина пока не подтверждена. Исчезновение плашки при рабочем встроенном дашборде не подтверждено. Используйте «Открыть отдельно», если iframe не работает.

Публичный репозиторий содержит только оболочку. Финансовых данных, снимков таблицы, токенов и серверного кода здесь нет. Вход Google и права исходного приложения сохраняются.

## Публикация

Settings → Pages → Deploy from a branch → main → / (root) → Save.
Ожидаемый адрес после успешной публикации: https://dinahalbaeva77.github.io/aprofi-dashboard/

## Подключение Apps Script

Для встраивания необходим метод `.setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL)` у HtmlOutput в существующей функции doGet(), затем обновление существующего развёртывания на новую версию. Метод разрешает встраивание на любых сайтах и требует отдельного решения владельца; он не меняет права Google на данные. До его применения встроенная страница может блокироваться.

Удалять проверку доступа, публиковать таблицу или включать анонимный доступ не требуется. Прямая ссылка доступна через «Открыть отдельно». Вход внутри iframe и исчезновение плашки требуют проверки в реальном браузере; не гарантируются этой оболочкой.

## Локально на Windows

Распакуйте ZIP и откройте index.html через Google Chrome. Требуется интернет. Для проверки входа используйте опубликованный HTTPS-адрес: поведение Google внутри локальной страницы может отличаться.
