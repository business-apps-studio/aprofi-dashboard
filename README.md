# А.Профи — оболочка дашборда

Страница открывает существующее приложение Google Apps Script на весь экран. Панель оболочки, дополнительные кнопки и инструкции из интерфейса удалены по запросу владельца.

Адрес: https://dinahalbaeva77.github.io/aprofi-dashboard/

Репозиторий содержит только оболочку без финансовых данных и серверного кода. Доступ к данным контролируется прежними правами Google.

## Запуск

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
Windows: распаковать ZIP, открыть index.html в Google Chrome. Нужен интернет; вход в Google лучше проверять по опубликованному HTTPS-адресу.

## Состояние подключения

24.10.2026 с согласия владельца опубликована версия Apps Script 4 с ALLOWALL. Прямая страница показывала актуальные данные, но встроенное окно в Chrome оставалось пустым. Удаление инструкций не решает эту отдельную проблему. Исчезновение плашки Google при рабочем встроенном дашборде пока не подтверждено.
